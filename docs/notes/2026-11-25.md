# 2026-11-25

- 0.6.1: adopted the NHR UI contract (shared `--nhr-*` tokens with the old values as fallback, `nhr-app` class, `window.nhrUi.theme`, `nhr_admin_parent_menu`). The screen looks the same when nothing sets them.
- 0.6.2, after the WordPress.org review: `Installer` keeps its version only once the table exists, so a failed create is tried again on the next `init`. The readme's `== Section ==` headings get a blank line after them.
- The review also said the primary key passes InnoDB's 767-byte limit on old MySQL. It doesn't: 767 bytes is the limit of one column in an index (`varchar(191)` utf8mb4 is 764), the key over all its columns may be 3072 (MyISAM 1000). The table was created on MySQL 5.5, 5.6 and MariaDB 10.1 with `innodb_large_prefix` off (Antelope, Compact) and on 5.7 and MariaDB 10.2, in Docker; a single `varchar(192)` key failed on the first three.
